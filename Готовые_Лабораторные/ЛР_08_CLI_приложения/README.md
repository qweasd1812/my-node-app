# Лабораторная работа № 8: CLI-приложения
**Студент:** Вдовиченко Егор Дмитриевич  
**Вариант:** 3  

## Описание
Разработка консольного интерфейса (CLI) с использованием библиотеки Commander.js.
Реализована обработка аргументов, флагов, подкоманд (`greet`, `build`), режимов `--dry-run` и `--env`.

## Запуск
```bash
npm install
node src/cli.js --help
node src/cli.js greet
node src/cli.js build --env=prod
```
