**Вариант:** 3  

## Описание
Практическое освоение встроенных низкоуровневых модулей Node.js:
1. `os` — сбор данных о хостовой операционной системе, памяти и ядрах процессора.
2. `events` — архитектура Observer/EventEmitter, эмитирование и перехват событий.
3. `http` — создание HTTP-сервера, обработка входящих запросов и формирование JSON-ответов.

## Запуск
```bash
node src/server.js
curl http://localhost:3000
```
