# Лабораторная работа № 11: Базы Данных (MySQL, MongoDB) и архитектура MVC
**Студент:** Вдовиченко Егор Дмитриевич  
**Вариант:** 3  

## Описание
Изучение принципов взаимодействия Node.js с СУБД (MySQL / MongoDB) и реализация архитектуры MVC:
- `Model` — инкапсуляция логики хранения и выборки данных.
- `Service` — реализация бизнес-логики и правил фильтрации.
- `Controller` — обработка входящих HTTP-запросов и форматирование JSON-ответов.

## Запуск
```bash
node src/server.js
curl http://localhost:3000/api/students
```
